# 后端联调与验证

联调使用仓库的原有前端、真实 Uvicorn HTTP 服务和临时 SQLite 文件。浏览器访问 `http://127.0.0.1:8080/frontend/`，API 监听 `127.0.0.1:8000`。演示记录均为虚构数据。

## 真实浏览器联调

| 步骤 | 已验证结果 |
| --- | --- |
| 启动空数据库并打开页面 | 前端显示空通讯录，成功访问后端 API。 |
| 新建和编辑联系人 | 同一联系人保存了 `001234`、`+86 555 0100` 两个电话和一个邮箱。编辑备注后列表同步更新。 |
| 收藏，再重启 Uvicorn 并刷新 | 页面仍显示收藏状态、两个电话及更新后的备注。 |
| 导入团队模板 | 新增一条联系人。重复上传同一模板新增零条。 |
| 搜索后点击导出 | 下载实际 `.xlsx` 文件。用 openpyxl 打开后确认包含两条记录，保留了电话的前导零、`+`、值的顺序和收藏状态。 |
| 上传损坏的 `.xlsx` | 页面显示后端错误提示，SQLite 中两条记录保持原状。 |
| 删除联系人 | 页面同步移除记录，查询 API 确认数据库只剩另一条记录。 |

## 自动化回归测试

按[后端运行说明](../../backend/README.md)安装测试依赖，在仓库根目录执行 `python -m unittest discover -s backend/tests -v`。6 项测试通过，覆盖 CRUD、收藏幂等性、数据库重启、字段校验、CORS、团队模板、工作簿往返、公式样文本、无效批次、文件和行数限制，以及并发重复导入。
